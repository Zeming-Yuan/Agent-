现有 Agent 项目
局域网多模态能力接入
保留现有 Agent 的使用入口与任务编排，由两台 Spark 提供本地推理和媒体处理服务。
项目目标与建议决策
建议将两台 128GB DGX Spark 建成现有 Agent 的内网模型与多模态服务层。用户继续在原项目中提问、上传文
件和发起任务，Agent 按任务调用模型及工具，统一返回答案和执行结果。

局域网架构与接入工作
用户 → 现有 Agent → 内网能力网关 → Spark01 主模型 / Spark02 媒体与音频 → Agent 汇总并执行后续工具 → 
原入口返回结果。
网关使用 Agent 可访问的业务局域网地址。Spark 间高速互联可用于内部数据传输；该专网地址不一定能被 Agent 服务
器访问，需单独验证路由。原则上模型端口仅对网关开放，Agent 通过独立凭证访问统一入口。
本次实际需要接入的接口
接入点 实施内容与责任边界
模型 Provider 在原项目新增本地模型配置与稳定模型别名。优先适配 OpenAI 风格接口；如使用 
Responses、Anthropic 或自定义协议，增加转换适配。
流式输出与工具调用 验证文本增量、结构化工具参数、调用 ID、工具结果回填及多轮续答。模型提出工具调用，Agent 执行并
回传结果；不能只改接口地址就认定兼容。
附件与媒体工具 复用原附件存储，或按权限复制到 Spark 暂存。提供文档分析、视频分析、转写和声音理解工具；以文件 
ID/受控引用传递，避免反复传整份大文件。
长任务与取消 耗时任务返回任务 ID，支持状态查询、进度与取消。结果包含摘要、页码/时间戳和引用；超时、重试与
重复提交规则统一。
调度与故障处理 对话优先、重任务有界排队；贯通 Agent 与推理服务的请求 ID。保留原模型配置用于人工或预设规则回
切，不自动外发本地文件到云模型。
文档、视频与音频如何进入 Agent
PDF 先提取文字并保留页码；扫描页和复杂版面交主模型分析。视频分段抽帧，音轨交 Whisper；需要解释声音时再调
用 Omni。将画面、逐字稿和声音描述按统一时间戳返回 Agent，供其综合推理和调用业务工具。
运行项 首期建议
上下文 每次模型请求总预算目标为 32K，含历史、工具定义、检索资料、视觉输入和输出；先验 16K，再验 
32K。长期记忆存储与检索，不全部塞入对话。
并发 按 1 路交互 + 1 路音频 + 1 个后台 PDF/视频任务验收；三模型保持加载。媒体先以 15–30 秒短片段处理。
内存与网络 规划每台保留约 20GiB 可用内存余量；控制像素、帧数和缓存。上传、下载、排队时间计入 Agent 用户的
实际等待。

阶段 工期估算 检查点
接口与模型验证 第 1–2 个工作日 确认内网连通、协议、鉴权、附件接口；验证三模型在隔离环境运行；确定
版本及接口清单。
Agent 联调 第 3–5 个工作日 接入 Provider、流式输出、工具调用和媒体工具；接通进度、取消、引用和

验收与交接 第 6–10 个工作日 从 Agent 入口测试中文业务场景、混合负载与至少 8 小时持续运行；修复并
交付操作说明。
验收必须从现有 Agent 入口发起
以下为拟定目标，均需实际测试。冻结模型/软件版本、业务样本和负载；模型响应速度与 Agent 完整任务耗时分开记录。
验收项 测试方法与目标
短文字模型响应 约 2K 输入/512 输出，关闭思考；单独及规定混合负载各 ≥100 请求。首字 P95 ≤5秒、每请求生成中位数 
≥30 token/s；网络和排队计入首字时间。
Agent 工具闭环 至少 20 个资料检索/浏览器/业务工具任务，≥18 个正确完成。验证参数、结果回填和多轮续答；记录完整
任务 P50/P95，不用模型 token/s 代替任务完成时间。
32K 与中文 PDF 32K 总预算内请求无越界/OOM；长请求时延单列。10 页清晰材料、≥50 个标注字段，正确率 ≥95%，引
用页码可核对。
语音与视频 20 段清晰普通话、合计 ≥10分钟：转写 ≥5倍实时，规范化字错误率 ≤10%。视觉和声音任务各 ≥20 道
标注题，正确率各 ≥85%，时间引用可核对。
故障与业务回归 验证超时、断连、取消、重复提交与权限拒绝；不重复执行有副作用的工具。原有会话、业务工具与回切路
径通过回归。
常驻与持续运行 三模型常驻，规定混合负载连续 ≥8小时，无服务崩溃/OOM/任务丢失；记录峰值内存、排队、重试和失
败；处理进度在原 Agent 可见。
首字时间是一次模型调用的等待；Agent 任务可能包含多轮模型、联网检索和工具执行。8 小时测试作为初次交付准入，后续继续记
录可用性与故障。

投入、风险与交付成果
投入项 首期安排
硬件与人员 计划新增硬件采购 0 元；复用两台 Spark 及 Agent 服务器。1 名实施工程师约 7–10 个工作日，需原项目维

运行费用 本地推理不向云模型按 token 付费；电费、运维、备份和现有/可选搜索 API 费用另计，按实际配置核算。
范围 在原 Agent 中接入本地能力，不另建独立聊天前端。首期按单用户低并发设计，语音播报、高并发与全天实
时视频监控另行评估。
